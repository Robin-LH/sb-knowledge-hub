# Understanding Your Accessibility Score

Your accessibility score reflects how well your website follows the Web Content Accessibility Guidelines (WCAG). A higher score means more people — including those with disabilities — can use your website effectively.

## How the Score Is Calculated

SiteBeacon evaluates your website against WCAG 2.1 Level AA criteria using automated testing. The score is presented as a percentage from 0 to 100.

The score considers:

- **Critical issues** (weight: high) — Problems that completely block access, such as missing alt text on images, empty links, or form fields without labels
- **Major issues** (weight: medium) — Significant barriers like poor color contrast, missing heading hierarchy, or inaccessible interactive elements
- **Minor issues** (weight: low) — Best practice improvements like redundant ARIA attributes or suboptimal tab order

## Score Ranges

| Range | Rating | What It Means |
|-------|--------|--------------|
| 90–100 | Excellent | Your website meets or exceeds WCAG 2.1 AA standards |
| 70–89 | Good | Most criteria are met, with a few areas for improvement |
| 50–69 | Needs Work | Several accessibility barriers exist that should be addressed |
| 0–49 | Critical | Major accessibility issues are present that block users |

## What SiteBeacon Tests

SiteBeacon runs a comprehensive set of accessibility checks, including:

### Images and Media
- Alternative text for images
- Captions and transcripts for video and audio
- Decorative images properly marked

### Navigation and Structure
- Logical heading hierarchy (h1 → h2 → h3)
- Skip navigation links
- Keyboard-accessible interactive elements
- Focus indicators on interactive elements

### Forms
- Labels associated with form fields
- Error messages clearly identified
- Required fields indicated

### Color and Contrast
- Text color contrast ratios (minimum 4.5:1 for normal text)
- Information not conveyed by color alone
- UI component contrast ratios

### ARIA and Semantics
- Correct use of ARIA roles and properties
- Semantic HTML elements used appropriately
- Landmark regions defined

## Improving Your Score

After each scan, SiteBeacon provides specific recommendations organized by priority. Focus on **critical issues first** — they have the largest impact on both your score and your users' experience.

For more context on the guidelines behind these checks, see [What is WCAG?](/learn/accessibility/what-is-wcag) in our Learn section.

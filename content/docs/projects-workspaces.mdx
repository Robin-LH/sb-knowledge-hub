# Projects & Workspaces

SiteBeacon organizes your monitored websites using a hierarchy of **Workspaces** and **Projects**.

## Workspaces
A **Workspace** is the highest level of organization. It houses your subscription plan, billing details, team members, and projects. 

You can belong to multiple workspaces (e.g., one for your personal side projects, and one for your company's official websites). You can switch between workspaces using the selector dropdown in the top-left corner of the SiteBeacon application dashboard.

## Projects
Inside a workspace, you create **Projects**. Each project is dedicated to monitoring a single website or domain.

### Creating a Project
1. Navigate to the dashboard of the target workspace.
2. Click **New Project**.
3. Input a friendly name and the primary homepage URL (e.g., `https://example.com`).
4. Select your preferred scanning frequency (e.g., Daily, Weekly, or Monthly).
5. Click **Create Project**. SiteBeacon will immediately run an initial crawl and audit.

### Project Settings
From any project page, click **Settings** to:
* Update the scan schedule.
* Configure crawler parameters (custom headers, basic auth username/password, etc.).
* Delete the project (note: deleting a project also deletes all its historical scan data).

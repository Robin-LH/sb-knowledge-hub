# Initial Release (v1.0)

We are thrilled to officially launch **SiteBeacon**, an all-in-one suite designed to audit and monitor your websites for accessibility compliance, performance standards, and digital sustainability.

Here is a breakdown of what is included in this launch.

---

## Key Features

### 🚀 Performance Audits
* Measures **Core Web Vitals** (LCP, CLS, INP) on mobile and desktop viewports.
* Provides detailed recommendations with estimated time savings for image optimizations, minification, and render-blocking resources.

### ♿ Accessibility Monitoring
* Runs automated audits checking against **WCAG 2.1 Level A & AA** specifications.
* Pinpoints the exact lines of code triggering issues (like missing `aria-label`, low contrast ratio, or incorrect tab-indexes).

### 🌱 Website Carbon Index
* Calculates carbon footprint estimates per page view based on data payload sizes.
* Checks server headers to detect if your web host is verified as running on **100% renewable energy**.

---

## Improvements & Tweaks
* Implemented clean multi-page crawlers matching internal links automatically.
* Supported team invitations with role permissions (Admin, Editor, Viewer).
* Added historical tracking charts showing score progression over the last 30 scans.
